# kmedia: задачи клиентов archive-stt

Что меняется в kmedia-admin, kmedia-mdb и archive-unzip. Сам archive-stt, его API и этапы — в [TODO.md](TODO.md);
этапы ниже — те же. Порядок: сначала archive-stt и kmedia-admin, kmedia-mdb — последним (решение 2026-11-23).

## Клиенты

- **kmedia-admin** (React 17, CRA, semantic-ui-react, `keycloak-js`): админка archive-stt — новый раздел. Там уже есть
  вход через Keycloak (`components/UserManagement.js`, `kc.hasRealmRole(...)`) и модерация меток
  (`components/labels`: список, принять / отклонить) — делать по тому же образцу. Клиент API:
  `REACT_APP_ARCHIVE_STT_URL`, функции рядом с `api.js` (или отдельный `archiveStt.js`).
- **archive-unzip** (Python, Flask): файлы MDB для kmedia — `doc2html`, распаковка рисунков (`/unzip`),
  время слов транскрипта (`/time_code` — заменяется archive-stt, убрать).
- **kmedia-mdb** (React 18, Vite, Redux Toolkit + Saga, Tailwind, i18next): разметка уже читается —
  `components/Pages/WithPlayer/widgets/LessonFlow` (`useLessonMarkup`, `fetchMarkup` в `redux/modules/assets`,
  главы, текущая глава, ссылка в транскрипт). Вход — `pkg/ksAdapter` (Keycloak).

### kmedia-mdb — к этапу «основа и чтение разметки (оригинал)»

- [ ] `fetchMarkup` → `GET /cus/{uid}/markup` (новый формат); коды спикеров → подписи через i18n (`public/locales/*`).

### kmedia-mdb — к этапу «поиск: время фрагментов и время ↔ текст (первоочередное)»

- [ ] «Играть с выделенного текста» (`fetchTimeCode` в `sagas/assets.js`, `PlayByTextBtn`) → `GET /cus/{uid}/timecode`
      archive-stt вместо `archive-unzip /time_code`. Сейчас `wordOffset` (`findOffsetOfDOMNode` в
      `WithText/scrollToSearch/helper.jsx`) — сквозной номер слова через пробелы в `textContent` всего текста, а
      `/time_code` нумерует по `clear_str(docx_to_text)` — отсюда расхождение и костыль `wordOffset - 2`. Перейти на
      `<p>` + номер слова в нём (как отдаёт `/timecode`), костыль убрать. Проверить, что `<p>` клиента = `<p>` `doc2html`.
- [ ] Результаты поиска: фрагменты подсветки → `POST /find` одним запросом → время у каждого фрагмента сразу
      в выдаче, переход в урок на это время.
- [ ] **Проиграть на странице поиска**: у фрагмента кнопка ▶ — встроенный плеер (аудио; видео — по желанию)
      с времени фрагмента, без ухода со страницы; играет до конца абзаца / главы или пока не остановят;
      одновременно играет один фрагмент.
- [ ] **Читать подробнее на странице поиска**: раскрыть фрагмент — абзац транскрипта целиком и соседние
      (по `p`, транскрипт kmedia `doc2html`), заголовок и тип главы; найденное подсвечено; ссылка
      «открыть урок здесь».
- [ ] Выделение текущего слова / абзаца в транскрипте (`/text?from&to`).
- [ ] Поиск фразы в уроке (`/find`) → перемотка.
